# Tetris

Тетрис для терминала на чистом ассемблере x86-64 (NASM) под Linux — без libc, только системные вызовы.

## Сборка

Нужны `nasm` и `ld` (binutils).

```sh
nasm -f elf64 main.asm -o main.o
ld main.o -o tetris
```

## Запуск

```sh
./tetris
```

Терминал должен поддерживать ANSI escape-последовательности (подойдёт практически любой современный).

## Управление

| Клавиша | Действие            |
|---------|---------------------|
| `a`/`d` | влево / вправо      |
| `w`     | поворот             |
| `s`     | на клетку вниз      |
| пробел  | мгновенный сброс    |
| `q`     | выход               |

За каждую убранную линию начисляется 1 очко.

## Как это устроено

- Поле 10×20; фигуры хранятся как 16-битные маски 4×4 — по 4 поворота на каждую из 7 фигур.
- Терминал переводится в «сырой» неблокирующий режим через `ioctl(TCGETS/TCSETS)`, при выходе настройки восстанавливаются.
- Игровой цикл тикает каждые 50 мс (`nanosleep`), фигура падает раз в 10 тиков (0.5 с).
- Случайные фигуры — xorshift64, зерно берётся из `rdtsc`.
- Кадр собирается в буфер и выводится одним вызовом `write`.
